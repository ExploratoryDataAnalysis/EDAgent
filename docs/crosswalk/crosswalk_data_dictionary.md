## 2. Table 1: Primary Crosswalk Table (`crosswalk_v1.0.0.csv.gz`)

The primary versioned crosswalk mapping every crash incident in the 2004–2024 analytical cohort ($N = 248,810$) to its primary roadway site.

| Column Name | Data Type | Nullable | Valid Values / Format | Description & Business Rules |
|---|---|---|---|---|
| `crash_id` | Integer | No | Positive Int64 (e.g. `2004000001`) | PennDOT Crash Record Number (CRN), matching canonical source column `CRASH_CRN`. |
| `crash_year` | Integer | No | `2004` to `2024` | Year the crash occurred. Matches `CRASH_YEAR`. |
| `primary_site_id` | String | Yes | `INT:...`, `SEG:...`, or empty string | **Stable Project-Level Site ID**. Non-empty if and only if `match_status == MATCHED`. Strictly empty if `AMBIGUOUS` or `UNMATCHED`. Enforces the One-Primary-Site Rule. |
| `site_type` | String | No | `INTERSECTION`, `SEGMENT`, `UNMATCHED` | Physical roadway category. `UNMATCHED` for unassigned crashes. |
| `road_class` | String | No | `INTERSTATE`, `STATE_ROUTE`, `COUNTY_ROAD`, `LOCAL_STREET`, `RAMP`, `UNKNOWN` | Administrative / functional classification derived from PennDOT road ownership and County FCC. |
| `match_method` | String | No | `EXACT_LRS`, `INTERSECTION_JUNCTION`, `SEGMENT_SPATIAL_SNAP`, `AMBIGUOUS_CONFLICT`, `AMBIGUOUS_MULTI_CANDIDATE`, `UNMATCHED_DISTANCE`, `UNMATCHED_MISSING`, `UNMATCHED_OUT_OF_BOUNDS` | Exact pipeline stage that resolved or gated the match. |
| `match_status` | String | No | `MATCHED`, `AMBIGUOUS`, `UNMATCHED` | Resolution status. `MATCHED` has exactly 1 primary site ID; others have zero. |
| `match_confidence` | String | No | `HIGH`, `MEDIUM`, `LOW`, `NONE` | Categorical confidence tier based on documented spatial and attribute corroboration. |
| `candidate_site_count` | Integer | No | Integer $\ge 0$ | Total number of candidate roadway features evaluated for this crash. |
| `snap_distance_meters` | Float | Yes | Metric float, or empty | Great-circle orthogonal distance from crash coordinates to matched site centroid/polyline. Empty for Stage 1 LRS or missing coordinates. |
| `source_reference_id` | String | Yes | E.g. `PENNDOT_RMS_02_0028_0010`, `AC_CENTERLINE_RCL58203` | Authoritative source reference ID from PennDOT or County GIS. |
| `coordinate_validation_status` | String | No | `VALID`, `WARNING`, `CONFLICT`, `INVALID`, `MISSING` | Provenance status propagated from Phase 3 Module B coordinate validation. |
| `crosswalk_version` | String | No | E.g. `1.0.0` | Semantic pipeline version producing this crosswalk. |

## 3. Table 2: Ambiguous Records Review Ledger (`ambiguous_records_review.csv`)

| Column Name | Data Type | Nullable | Example Value | Description |
|---|---|---|---|---|
| `crash_id` | Integer | No | `2007016949` | PennDOT Crash Record Number (CRN). |

| `original_longitude` | String | Yes | `79 10:45.370` | Raw police DMS longitude text as reported in source dataset. |
| `original_dec_lat` | String | Yes | `40.4355011` | Raw state route decimal latitude as calculated in source dataset. |
| `original_dec_long` | String | Yes | `-79.74880219` | Raw state route decimal longitude as calculated in source dataset. |
| `street_name` | String | Yes | `PENN AVE` | Street name recorded on crash report. |

| `candidate_site_count` | Integer | No | `2` | Number of competing candidates. |

## 4. Table 3: Coordinate Disagreements Ledger (`coordinate_disagreements_review.csv`)

Audits all spatial disagreements between crash coordinates and reference geometries without hiding them through forced snapping.

| Column Name | Data Type | Description |
|---|---|---|
| `crash_id` | Integer | Crash Record Number. |
| `crash_year` | Integer | Crash year. |
| `discrepancy_type` | String | `POLICE_STATE_COORDINATE_CONFLICT` or `EXCEEDS_MAX_ROAD_SNAP_DISTANCE`. |
| `distance_meters` | Float | Spatial distance (meters) between discordant coordinates or to nearest road. |
| `coordinate_source` | String | Origin of evaluated coordinates (`police_dms_vs_state_decimal`, `decoded_crash_gps`). |
| `reference_dataset_version` | String | Dataset vintage used as reference (`2026.10` or source UUID). |
| `candidate_site_count` | Integer | Count of nearby reference sites. |
| `match_method` | String | Resulting match method code. |
| `road_class` | String | Road classification. |
| `primary_site_id` | String | Assigned site ID (or `NONE`). |
| `review_status` | String | `FLAGGED_CONFLICT` or `NEEDS_MANUAL_LOCATION_REVIEW`. |
| `notes` | String | Explanatory notes detailing threshold breaches. |

## 5. Stratified Quality Summaries

All stratified summary tables report both counts and percentages with explicit mathematical denominators.

### 5.1 Annual Summary (`stratified_summary_by_year.csv`)
- **Columns**: `crash_year`, `matched_count`, `matched_pct_annual`, `matched_pct_cohort`, `ambiguous_count`, `ambiguous_pct_annual`, `ambiguous_pct_cohort`, `unmatched_count`, `unmatched_pct_annual`, `unmatched_pct_cohort`, `annual_total`, `annual_pct_of_cohort`, `annual_denominator`, `cohort_denominator`.
- **Denominators**:
  - `annual_denominator`: Total crashes occurring in that specific year (e.g. $N_{2004} = 12,535$).
  - `cohort_denominator`: Total crashes in full study period ($N = 248,810$).
- **Completeness**: Explicitly includes all 21 calendar years from 2004 to 2024.

### 5.2 Road Class Summary (`stratified_summary_by_road_class.csv`)
- **Columns**: `road_class`, `matched_count`, `matched_pct_category`, `matched_pct_cohort`, `ambiguous_count`, `ambiguous_pct_category`, `ambiguous_pct_cohort`, `unmatched_count`, `unmatched_pct_category`, `unmatched_pct_cohort`, `category_total`, `category_pct_of_cohort`, `category_denominator`, `cohort_denominator`.
- **Categories**: `INTERSTATE`, `STATE_ROUTE`, `COUNTY_ROAD`, `LOCAL_STREET`, `RAMP`, `UNKNOWN`.

### 5.3 Site Type Summary (`stratified_summary_by_site_type.csv`)
- **Columns**: `site_type`, `matched_count`, `matched_pct_category`, `matched_pct_cohort`, `ambiguous_count`, `ambiguous_pct_category`, `ambiguous_pct_cohort`, `unmatched_count`, `unmatched_pct_category`, `unmatched_pct_cohort`, `category_total`, `category_pct_of_cohort`, `category_denominator`, `cohort_denominator`.
- **Categories**: `INTERSECTION`, `SEGMENT`, `UNMATCHED`.

### 5.4 Method Summary (`stratified_summary_by_method.csv`)
- **Columns**: `match_method`, `count`, `percentage`, `cohort_denominator`.

### 5.5 Coordinate Status Summary (`stratified_summary_by_coord_status.csv`)
- **Columns**: `coordinate_status`, `count`, `percentage`, `cohort_denominator`.

## 6. Table 4: Reproducibility Manifest (`reproducibility_manifest.json`)

Machine-readable JSON document storing:
- `crosswalk_version`: `1.0.0`
- `generation_utc`: Timestamp in ISO 8601 UTC
- `software`: Python version, OS platform, package version
- `parameters`: Distance tolerances ($50.0\text{ m}$ snap, $30.48\text{ m}$ intersection, $2.0\text{ m}$ tie, $500.0\text{ m}$ conflict)
- `inputs`: File paths, record counts, and input SHA-256 hashes
- `outputs`: Cryptographic SHA-256 hashes for all 9 exported deliverable files
- `summary_metrics`: Total records processed, counts by status, throughput rate.
